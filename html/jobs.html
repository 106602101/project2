Reference FW1001

Cybersecurity Operations Analyst

Monitor security activity, investigate alerts and support cybersecurity incident response.

  • Salary: AUD $75,000–$90,000 + super
  • Employment: Full-time
  • Location: Melbourne, VIC — Hybrid
  • Reports to: Senior Security Operations Lead

FABWEB is seeking a Cybersecurity Operations Analyst to join its Security Operations team. The analyst will monitor alerts, investigate suspicious activity and assist with cybersecurity incident response.

Key Responsibilities

  1. Monitor alerts generated by security monitoring platforms.
  2. Investigate unusual network, account and system activity.
  3. Assist with identifying and classifying security incidents.
  4. Escalate significant incidents to senior security staff.
  5. Review security logs during investigations.
  6. Document incident findings and response activities.

Essential Requirements

  • Study or qualification in cybersecurity, IT or computer science.
  • Basic understanding of networking and internet protocols.
  • Knowledge of common cybersecurity threats.
  • Familiarity with Windows and Linux environments.
  • Strong analytical and communication skills.

Preferable Requirements

  • Familiarity with SIEM platforms.
  • Understanding of incident response processes.
  • Basic Python, Bash or PowerShell knowledge.

Reference FW1002

Penetration Tester

Conduct authorised security assessments and identify vulnerabilities in approved systems.

  • Salary: AUD $90,000–$115,000 + super
  • Employment: Full-time
  • Location: Melbourne, VIC — Hybrid
  • Reports to: Offensive Security Team Lead

FABWEB is looking for a Penetration Tester to perform authorised security testing of websites, applications and network environments.

Key Responsibilities

  1. Perform authorised penetration tests.
  2. Assess web applications for security vulnerabilities.
  3. Review authentication and access-control mechanisms.
  4. Conduct network vulnerability assessments.
  5. Verify vulnerabilities and assess their impact.
  6. Prepare professional security assessment reports.

Essential Requirements

  • Understanding of networking and operating systems.
  • Knowledge of common web application vulnerabilities.
  • Knowledge of the OWASP Top 10.
  • Familiarity with security assessment tools.
  • Strong analytical and troubleshooting skills.

Preferable Requirements

  • Experience with Burp Suite.
  • Knowledge of Linux security tools.
  • Python or Bash scripting experience.
  • Relevant cybersecurity certification.

  • Salary: AUD $105,000–$135,000 + super
  • Employment: Full-time
  • Location: Melbourne, VIC — Hybrid
  • Reports to: Cloud Security Manager

The Cloud Security Engineer helps FABWEB clients review cloud infrastructure, identities, access permissions, logging and security configurations.

Key Responsibilities

  1. Review cloud environments for security weaknesses.
  2. Assist clients with secure cloud architecture.
  3. Review identities, roles and access permissions.

  • Knowledge of AWS, Microsoft Azure or Google Cloud.
  • Understanding of identity and access management.

Preferable Requirements

  • Employment: Full-time
  • Location: Melbourne, VIC — Hybrid
